# Morfa brand

The brand files. The app draws the same shapes inline from
`src/brand/marks.tsx`, so they can take each background's colours; the favicon (`public/favicon.svg`,
`public/favicon-32.png`, `public/apple-touch-icon.png`) and the desktop app's icons (`desktop/icon-source/`,
`desktop/src-tauri/icons/`) are made from `morfa-app-icon.svg`.

| File | What it is |
|---|---|
| `morfa-symbol.svg` | The symbol in colour: a square, a rounded square and a circle (#C4C0FF, #8A82FF, #4338FF) |
| `morfa-symbol-mono.svg` | The symbol in greys, for light grounds (#D2D2D2, #8C8C8C, #141414) |
| `morfa-symbol-mono-on-dark.svg` | The symbol in greys, for dark grounds (#3A3A3A, #8C8C8C, #FFFFFF) |
| `morfa-wordmark.svg` | "morfa", lowercase, #141414 |
| `morfa-lockup.svg` | Symbol and wordmark, for light grounds |
| `morfa-lockup-on-dark.svg` | Symbol and white wordmark on #141414 |
| `morfa-app-icon.svg` | The app icon: the symbol (#6E66FF, #A9A3FF, white) on the brand colour #4338FF |
| `morfa-app-icon-dark.svg` | The app icon on #141414 with the colour symbol |

The brand colour is #4338FF. White text on it reads at 6.5:1.
